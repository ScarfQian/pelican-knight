# 鹈鹕骑士 · 海风镇与海岸

更新日期：2026-10-27  
创建人：ScarfQian  
整理与开发记录：Codex

一只默认步行的鹈鹕，从可自由移动的海风镇出发，在横版海岸试炼中使用武器、骑乘车辆、收集珍珠并抵御敌潮。游戏使用原生 HTML、CSS、JavaScript 与 SVG，所有运行内容内嵌在单个 HTML 中，无安装、构建或外部资源依赖。

当前 **0.3.2** 将 37 项活跃资产优化为 r2：修正鹈鹕嘴部连接，完善人物、怪物、武器、穿戴、车辆、建筑与辅助物件的轮廓和材质，仍按固定编号复用。游戏仍是**实现原型，行为体验待验证**；尚未运行游戏、浏览器试玩、自动化测试、移动端实测或性能测试。

## 固定资产与复用

查看 [40 张资产卡片](docs/assets.html)、[PNG 总览](docs/assets-overview.png)、[嘴部对照与换装组合](docs/assets-detail.png)及[复用约定](assets/README.md)。其中 31 项为人物、怪物、武器、穿戴、车辆及建筑设施，另有 6 项辅助物件和 3 项历史素材。37 项活跃资产已升为 r2，3 项历史素材保留 r1。每项登记固定 ID、修订号、现有造型、挂点/尺寸、动作边界、运行定义与关联对象。

资产维护来源是 [catalog.json](assets/catalog.json) 与 [sprites.svg](assets/sprites.svg)。游戏玩法仍在 `index.html` 开发，资产生成区由 `python3 tools/sync_assets.py` 同步；图鉴取自相同来源。实际运行仍只需要一个 HTML，不增加网络、服务器或构建依赖。资产源拆出是为了避免不同场景反复重画同一对象。

新场景和装备组合优先引用已有编号与图形；数值调整不自动改造型。需要重设计时修改对应源并递增修订号，不能直接覆盖生成区。PNG 总览和组合对照由现成运行时的 `sharp` 离线导出，是可选维护工具，不是游戏依赖。当前造型是本次优化结果，尚不代表用户确认美术定稿。

本轮图形变化包括连贯的上喙与喉囊、六武器的材质与握持方向、两种不同纹样的围巾、四车的机械结构、精英蟹独立甲壳、建筑立面与开放设施陈列。围巾动画改为摆动整个飘带图层，避免运行时覆盖各自的轮廓和纹样；没有改变伤害、价格、碰撞、存档格式或玩法规则。

## 启动与操作

直接用现代浏览器打开 [index.html](index.html)，自动进入海风镇。角色可自由行走；靠近入口按 E 或点击交互按钮。下方路标会让角色走向所选建筑，到达后打开窗口；手动移动可取消自动行走。

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 左右移动与少量前后走位 | WASD / 方向键 | 左侧摇杆 |
| 普通攻击 | J，可按住 | 按住攻击 |
| 武器特色 | K；蓄力/举盾按住，其余点按 | 特色按钮 |
| 跳跃 / 可用时的坐骑跳击 | 空格 | 跳跃 |
| 闪避 / 公路车与摩托的冲撞 | Shift | 动作按钮 |
| 上下车 | R | 坐骑按钮 |
| 靠近交互 | E | 交互 |
| 暂停 / 继续 | P / Esc | 暂停与继续按钮 |
| 局内三选一 | 1 / 2 / 3 | 点击卡片 |

角色的地面位置、前后纵深与跳跃高度分开计算；跳跃不自动获得全程无敌。普通闪避持续约 0.19 秒，默认冷却 2.6 秒；公路车和摩托车的 Shift 则是有伤害的冲撞，没有全程无敌。打开窗口时冻结移动与战斗，升级与结算窗口需完成选择。

| 顶部行囊 | 查看海贝与新旧纪录，导出 JSON 存档；保存失败时重试 |

水手帽和红帆围巾初始免费持有；护航帽、海风围巾各需 16 海贝。每件装备从 0 级开始，三级强化依次花费 12、24、36 海贝，换下后保留等级。水手帽提高最大体力，护航帽提供固定减伤，红帆围巾提高武器伤害，海风围巾提高移动速度；穿戴外观会随配置变化。

天赋每节点消耗 1 出战点，初始有 3 点，领取委托后增加，上限 6 点。取消前置节点会同时移除其后续节点并退点。五项委托分别为正常结算一次、累计击退 50 个敌人、强化一次、激活一个天赋、横版获胜一次；奖励依次为 12、18、8、6、24 海贝。

| 太刀 · 竹柄太刀 | 三段连斩；蓄力后前向居合 |
| 巨型双手武器 · 木柄巨锤 | 较慢的大范围重砸；蓄力强化范围与伤害，砸击带击退 |

| 散弹枪 · 木托散弹枪 | 4 发弹仓，每发 6 枚散弹；约 1.3 秒装填，距离与同发后续命中衰减 |

| 坐骑 | 速度倍率 | 固有能力 |
| --- | --- | --- |
| 普通自行车 | ×1.30 | 加速、普通跳跃和闪避 |
| 山地车 | ×1.35 | 落地震击 55 伤害，专属冷却 4 秒 |
| 公路车 | ×1.65 | 冲撞 62 伤害，持续 0.45 秒，冷却 5 秒；同次动作不重复命中同一目标 |

速度倍率以相同装备与天赋下的步行为基准。四类基础坐骑本版全部开放，方便体验不同能力；它们的永久解锁进度暂不作为门槛。出发、返回营地均默认步行；仅在地面空闲时上下车，冷却不因此重置。骑乘时六种武器仍可使用，坐骑动作与武器动作分别管理。上述数值是当前实现参数，尚未验证平衡。

## 海岸、资源与存档

海岸试炼保留“生存 180 秒且首领已被击败”的胜利条件；首领在 135 秒登场，四次敌潮位于 35、75、110、165 秒。首领初始体力改为 1250，出怪、伤害、移动与弹道已按横版重设，不能沿用旧版的平衡判断。体力耗尽时失败。击败敌人掉落珍珠，触发八类通用局内升级的三选一；临时成长不跨局保留。

| 情况 | 结算 |
| --- | --- |
| 每完成 30 秒 | 正常结算时获得 2 海贝，最多计六段、12 海贝 |
| 正常获胜 | 阶段收益外再加 6 海贝 |
| 正常失败 | 保留已完成阶段收益，并保存本局纪录和累计击退 |
| 主动退出 / 重开 | 需确认，不结算本局收益或任务进度 |
| 刷新 / 关闭页面 | 不提供中途续局，未结算收益放弃；此前永久成长保留 |

永久档使用 `localStorage` 的 `pelican-knight-save-v1`，格式版本 `schemaVersion: 1`。装备配置与等级、海贝、天赋、委托、纪录及设置会自动保存。首次创建新档时，旧 `pelican-coast-best-v1` 的最佳击退、最长时间和胜利次数只导入独立的旧版纪录，旧键保留；旧纪录不兑换新资源，也不计入横版胜利或任务。

结算只写入一次；返回营地不重复领奖。购买和配置要保存成功才生效。若存储不可用或写入失败，界面会明确提示；结算结果留在当前页面，可重试保存或导出。当前支持 JSON 导出，不含导入、云存档或账号同步。`file://`、本地 HTTP 与 GitHub Pages 的存储来源互相独立。
