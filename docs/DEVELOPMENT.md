### 既有开发成果

初始请求是一个 SVG 鹈鹕骑自行车的二维动画。该原型包含踩踏、轮转、围巾摆动、海岸视差、暂停和三档速度。随后用户要求转为肉鸽游戏，当前实现为俯视角生存玩法，使用相同角色与海岸视觉。

已写入游戏的核心循环为：

移动与闪避 → 自动攻击敌人 → 拾取珍珠 → 随机三选一升级 → 对抗增强敌潮与首领 → 胜负结算及重新开始。

这些描述依据当前 HTML 代码；本对话按用户要求未运行测试。
